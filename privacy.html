Privacy policy

Health tracker is a personal tool used only by its developer.

  • Data accessed: the developer's own Google Health data (activity and fitness, health metrics and measurements, sleep, mindfulness), with read-only access.
  • Use: the data is used only to produce daily and weekly summaries for the developer's personal notes.
  • Storage: the data is stored only on the developer's own computer. There is no server and no database operated by this app.
  • Sharing: the data is not sold, shared with, or transferred to any third party.
  • Other users: the app is not offered to anyone else and collects no data from any other person.
  • Revoking access: access can be removed at any time at myaccount.google.com/permissions.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
